# LeetCode 175章Notebook课程生成规格包

版本1.0 · 2026-09-23

## 包含什么

**175个固定Notebook路径、22个模块、383道去重代表题。** 每章均指定教学目标、知识点、代表题、必须实现代码、可视化、练习和单元测试，并记录先修、运行时、难度、拓展边界。

本包是课程目录及生成规格，**没有生成175个.ipynb，没有执行未来的算法或单元测试**。已完成的是规格完整性与先修依赖验证。

| 文件 | 用途 |
|---|---|
| `COURSE_CATALOG.md` | 人类阅读入口：完整文件树和175章逐章七项规格。可直接放入Obsidian。 |
| `curriculum.json` | AI生成入口：唯一结构化课程清单，包含固定路径及合法先修顺序。 |
| `GENERATION_PROMPT.md` | 分批生成与验收指令，可直接交给具有文件和执行能力的AI Agent。 |
| `problem_references.json` | 383道代表题与章节的多对多映射、题目角色和核验状态。不是全站题库。 |
| `validation_summary.json` | 本轮规格校验结果，不是Notebook或算法的测试报告。 |
| `SOURCES.md` | 官方学习计划、运行工具文档与核验范围。 |

## 如何交给AI

将本目录作为工作上下文，使用`GENERATION_PROMPT.md`。首次指定：

```text
读取curriculum.json与GENERATION_PROMPT.md。
本轮生成N001–N003，严格使用各记录的path。
按七项规格生成、执行、测试和修复，不创建其他空Notebook。
报告实际文件、空内核执行结果和未完成项。
```

后续按`learning_order`推进。该顺序是经校验的先修拓扑序，并优先安排可学习的基础与主线，不要求按001至175机械学习。专门技能分支也可在各自先修满足后独立学习。

编号表示知识目录，不表示先修必然是更小编号。例如状态压缩前需位运算，概率DP前需概率基础。`optional_code`不阻塞核心完成；只有采用拓展实现时才要求`optional_prerequisites`。

## 课程组成

算法和编程基础151章；SQL5章、Pandas3章、Shell1章、JavaScript3章、并发4章；综合迁移与结业8章。合计175章。

题目角色为典型、热身、预告、对照和拓展。一个题可以在不同阶段用于不同机制；不要求每次都重写一篇完整题解。高级算法不因为更复杂就成为推荐默认解法。

## 已验证与未验证

已验证：175条连续编号、175个唯一合法路径、每章七项必需字段非空、全部先修引用存在、依赖无环、生成顺序合法、各模块数量匹配、同一题号标题一致。

本轮访问官方页面重点核对了34道代表题的身份。其余题目在`identity_status`中标记为`verify_before_generation`，生成涉及该题的章节前须读取官方题面。未做付费状态、逐题语言支持和全题库覆盖率核验。

测试规格中的样例和性质是未来代码的验收要求，不等于已通过。读题、正确性论证、单元测试、性能测量和教学质量需要在实际生成时分别完成。

## 核心执行边界

算法Notebook默认Python内核。SQL用真实SQLite内存表执行；其他方言未执行就标为未测。Pandas比较值、列、索引与dtype。Shell和JS分别调用真实Shell工具、Node.js；缺依赖就报告阻塞，不用Python改写后冒充通过。并发实验用子进程限制挂起风险，不能用sleep替代同步或用有限测试冒充活性证明。
